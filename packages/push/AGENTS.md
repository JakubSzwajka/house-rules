# @house-rules/push: notes for agents

Push owns party-owned device subscriptions and the `PushSender` delivery port. Import `PushMount` from the main door and add `{ ...PushMount, layer: chosenLayer }` to the module plan. Register `{ "workspace": "packages/push" }` in `migrations.json`.

`Push.layerMemory(options?, senderLayer?)` captures the rollback-aware in-memory store and a memory sender. `Push.layerPostgres(options?, senderLayer?)` captures Postgres storage and the console sender for development. Production apps pass their own `PushSender` layer as the second argument. `options.defaultTtlSeconds` is a positive integer defaulting to 86400; an optional positive integer `ttl` on the deliver input overrides it. `Push.layer(options)` requires both `PushStore` and `PushSender`. A web-push adapter should implement `PushSender.send(subscription, payload, { ttl, idempotencyKey })`, return `"sent"` on acceptance, return `"gone"` only for provider 404/410 responses, and fail with `PushSendFailed` for other send failures. The app chooses and provides that adapter. No web-push library is bundled.

An app delivery system feature has an edge to `Push.deliver`, never calls `PushSender` directly. Deliver takes `{ owner, payload, idempotencyKey, ttl? }`, requires `push:deliver`, and is transactional. It sends to active subscriptions, soft-expires `"gone"` endpoints and returns `{ sent, expired, events: SubscriptionExpired[] }`. Person callers receive `PushSubscriptionNotFound`. A sender failure fails with `PushSendFailed` and rolls back the unit, including earlier expiries. Expired endpoints stay expired only if the unit commits. Provider sends cannot roll back; the delivery ledger retries with the same idempotency key. Run delivery after the originating commit in a separate system feature unit.

Nothing sends automatically. `forgetExpired` also soft-marks `expiredAt` and returns `SubscriptionExpired`; reads exclude marked rows. Re-subscribing clears expiry and retains `createdAt`. Repeating an active subscription for the same owner returns it unchanged with no events. Operations return event facts as data; the module does not emit events. `erase(owner)` is a cascade hook, not an operation, and must join the owner's deletion unit.

Non-person subscribe/unsubscribe calls return `PushSubscriptionNotFound`. Subscribe validates HTTPS endpoints and nonempty keys, failing with `PushInputInvalid`. `Push.layerMemoryTesting(options?, senderOptions?)` exposes the facade and `MemoryPushOutbox.sends` for inspecting every attempt, including attempts from rolled-back units. `memoryPushSender({ results })` configures sent/gone/fail by endpoint. Console delivery logs no keys or payload body.

Subscription writes require an open unit. Memory rollback restores prior state. Postgres uses the shared SQL transaction. The module never opens units.
