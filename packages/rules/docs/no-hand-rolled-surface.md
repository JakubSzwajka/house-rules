# no-hand-rolled-surface

Describe actions with domain defineOperation, bind them once, choose app entries and expose those entries through defineWay. The application router builds the HTTP endpoints and MCP toolkit. Apps do not call Tool.make, Rpc.make or HttpApiEndpoint methods by hand.

The rule resolves actual Effect imports, including named aliases, namespace imports and the stable/RC paths. A local object with the same spelling is not an Effect builder. The default implementation exemption is packages/application only; a consumer can supply its documented allow list without broadening the plugin preset.

Enable configs.features or featuresConfig({appsDir,packagesDir}). It checks the same JS/TS extensions as recommended. Toolkit.make is not one of the banned calls. no-hand-run-effect and testing-export restrictions remain separate checks in the features preset.
